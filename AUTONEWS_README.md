# ARCHIUM — автоматические новости с ручным подтверждением

**Автопубликация отключена.** Код в отдельном PR, расписание включится только после его слияния в default branch. Содержимое публичного сайта и news.json в main пока не меняются.

## Принцип
- Каждые 3 часа UTC: 00:23, 03:23, 06:23 и далее. Возможны задержки GitHub Actions.
- Источник: Steam News API, S.T.A.L.K.E.R. 2 AppID 1643320.
- Срок новостей до 14 дней, не более 5 новых кандидатов за запуск.
- Проверка дублей по ID/ссылке, даты и домена HTTPS.
- Создаётся только черновой pull request с предлагаемой версией news.json. До ручного merge новость не появится на сайте.
- Редактор проверяет первоисточник, переводит и уточняет русский текст. Генератор не копирует статью целиком и не выдумывает подробности.
- Если открыт старый review-PR, новые не создаются. Старые статьи сохраняются.

## Проверка и включение
Команда тестов: python -m unittest discover -s tests -p 'test_news*.py' -v

После одобрения этого PR появится Actions → ARCHIUM · поиск новостей на модерацию → Run workflow. Режим dry_run=true создаёт только artifact, без PR и без публикации.

## Как одобрить новость
Pull requests → ARCHIUM: новости на проверку → проверить ссылки и даты → при необходимости отредактировать news.json → Ready for review → Merge pull request. Только ручной merge обновляет публичную новостную ленту.

## Настройки
Если создание PR запрещено: Settings → Actions → General → Workflow permissions → Allow GitHub Actions to create and approve pull requests. Workflow никогда не одобряет и не сливает PR.

## Ограничения
Сейчас отслеживается только Steam S.T.A.L.K.E.R. 2, не моды, Telegram или новости ЧАЭС. Cron работает только в default branch. Основной сайт ARCHIUM MAIN 8.5 локальный, а archium-beta — подключённый к GitHub сайт с совместимым news.json. Репозиторий Arhium пока не содержит корневых index.html и news.json.
